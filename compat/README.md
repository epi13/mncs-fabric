# Compatibility snapshots

This directory contains small, pinned shape snapshots rather than a vendored
copy of a sibling implementation. The receipt snapshot was inspected against
`machine-native-complexity-standard` commit `160358365c4bec8c2c0038e2e2e69da7c4b06911`.

Fabric emits the experimental MNCS typed execution receipt as a companion
observation. It does not emit conformance, assurance, independence, custody,
sandbox, or attestation claims. Unknown future receipt versions are rejected.
